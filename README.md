# 💰 Expense Tracker & Spending Analysis (Python Project)

## 📌 Overview
This project is a Python-based expense tracker that analyzes bank statement data to help understand spending habits, category distribution, monthly trends, and budget performance.

It also includes a simple machine learning model to predict future spending and a Streamlit dashboard for interactive visualization.

---

## 🎯 Project Goals
- Track and analyze personal spending
- Categorize transactions
- Identify high and low spending areas
- Monitor monthly spending trends
- Set and evaluate budget limits
- Predict future spending using simple ML

---

## 📊 Features
- Data cleaning and preprocessing using Pandas
- Expense filtering (separating income vs spending)
- Category-wise spending analysis
- Budget alert system
- Monthly spending trend analysis
- Data visualizations (bar, line, pie charts)
- Simple linear regression prediction for next month spending
- Interactive dashboard using Streamlit

---

## 🛠️ Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

---

## 📁 Dataset Structure
The dataset contains:
- Date (transaction date)
- Category (e.g. Food, Transport, Shopping)
- Amount (transaction value)

---

## 📈 Key Insights Generated
- Highest spending category identified
- Lowest spending category identified
- Monthly spending trends visualized
- Budget exceed alerts per category
- Predicted next month spending amount
